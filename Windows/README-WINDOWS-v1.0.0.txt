iPhone 5 DualBooter for Windows v1.0.0

-CoolBooterCLI exit code -1 success in the running/reboot result.
- Prints a message every 30 seconds while CoolBooterCLI is silent.
- Installs the CoolBooter untether before booting when selected.
- Runs coolbootercli -b after installation.
- Without the untether, pauses after the first boot/configuration pass and asks you to confirm the phone is back in the main OS, then runs coolbootercli -b again.
- Shows the instructions for booting the secondary OS again later.
