# Third-party components

This project does not bundle Apple firmware, APTickets/SHSH, jailbreak payloads,
Legacy iOS Kit, CoolBooter packages, usbipd-win, or Apple USB drivers.

Relevant upstream projects retain their own licenses and copyrights:

- Legacy iOS Kit / LukeZGD
- CoolBooter
- usbipd-win / Frans van Dorsselaer
- Paramiko
- Qt / PySide6

The GUI coordinates user-supplied firmware and separately installed or
runtime-downloaded tools.
